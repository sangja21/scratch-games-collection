# 쿠키 대 개미 (cookies-vs-ants) — Plan

> **설탕을 모아 5개 레인 그리드에 장치를 설치하고**, 오른쪽에서 레인을 따라 **왼쪽 창고로 걸어오는 귀여운 만화 개미**를 막아내는 **쿠키 공장 레인 타워디펜스.** 개미는 자기 레인을 따라 왼쪽으로만 행진하고, 장치에 닿으면 멈춰서 오독오독 갉아먹는다. 마우스로 **위쪽 메뉴판에서 장치를 고르고 컨베이어 칸을 클릭**해 심는다(설탕이 충분하고 빈 칸일 때만). **설탕기계**는 주기적으로 설탕을 만들고(클릭해서 줍기), **쿠키캐논**는 자기 레인에 개미가 있으면 쿠키캐논을 오른쪽으로 쏘며, **초코벽**는 체력이 높아 개미를 오래 막고, **밀크폭탄**은 짧은 도화선 뒤 넓은 범위를 한 방에 쓸어버린다. 개미가 창고 앞까지 오면 **레인당 한 번 빗자루**가 발동해 그 레인을 싹 밀어버리고(1회 소모), 빗자루를 이미 쓴 레인이 또 뚫리면 `목숨`이 1 깎인다. 웨이브가 오를수록 개미가 더 많이·세게·빠르게(+헬멧 개미·빠른 개미 해금) 몰려오고, `목숨`이 0이 되면 GAME OVER → 깃발을 다시 누르면 1웨이브부터. **점수 = 잡은 개미 수(+도달 웨이브).**
> 베이스: `games/castle-defense/build.py` (한글 튜닝 변수 **일괄 초기화**·매직넘버 0 / 웨이브 매니저 / 클론 스포너 + `복제됨` 가드 / `타격` **broadcast-and-wait 반경 데미지** / 자동 조준 핸드셰이크(→레인 감지로 변형) / 플로팅 숫자 팝업(say 미사용) / 게임오버 배너 / 전용 합성 효과음 `_wav_bytes`·`synth_*` / `add_comment` 가이드 투어 / 팔레트·건설커서 → 메뉴판·설치커서로 변형).
> 학습 콘셉트 없음(직관적 액션 — 추상 학습개념 금지, [[feedback-game-design]] 준수). **진짜 가치는 캐슬 디펜스와 똑같이 "아이가 코드의 숫자·규칙을 직접 바꾸며 노는 것"** — 모든 조절 값을 한글 전역 변수로 노출, 코드 어디에도 매직넘버 없음. 시후(초등·성격 급함)를 위해 **템포를 빠르게**: 짧은 첫 웨이브 대기, 읽기 쉬운 설탕 경제(설탕기계+하늘 설탕), 한 번에 너무 많은 쿠키알 클론이 안 나오게 발사 간격으로 상한, 심기·수확·발사 손맛(전용 효과음). ★★★★☆.

- **주제**: 레인 타워디펜스 (장치 vs 귀여운 개미, 쿠키 공장 디펜스 lite)
- **카테고리**: 액션 · 레인 타워디펜스
- **난이도**: ★★★★☆
- **폴더**: `games/cookies-vs-ants/`
- **출력 파일**: `쿠키_대_개미.sb3`
- **빌드**: `python3 games/cookies-vs-ants/build.py`

## 1. 게임 한 줄

오른쪽에서 5개 레인을 따라 왼쪽 창고로 걸어오는 만화 개미를, 공장 그리드에 장치를 심어 막아낸다. 설탕기계가 만드는 설탕(과 하늘에서 떨어지는 설탕)을 클릭해 모으고, 그 설탕로 쿠키캐논·초코벽·밀크폭탄을 심는다. 쿠키캐논은 레인에 개미가 오면 알아서 쏘고, 초코벽는 몸으로 막고, 밀크폭탄는 한 방에 무리를 쓸어버린다. 창고 앞이 뚫리면 레인당 한 번 빗자루가 구해주지만, 두 번째로 뚫리면 목숨이 깎인다. 웨이브가 오를수록 개미가 더 많이·세게 오고, 목숨이 0이 되면 GAME OVER, 깃발을 다시 누르면 1웨이브부터(점수 = 잡은 개미 수).

## 2. 화면 레이아웃 (480×360)

좌표계: SVG/무대 픽셀(0~480, 0~360) ↔ Scratch 좌표(-240~240, -180~180). 변환: `scratchX = svgX - 240`, `scratchY = 180 - svgY`.

```
 (-240,180)                                            (240,180)
   ┌──────────────────────────────────────────────────────┐
   │ ☀️설탕:５０  🌊웨이브:１  💀점수:０  ❤️목숨:３            │ ← 좌상단 HUD 모니터 4종
   │ ┌[🌻25][🌱50][🥜25][🍒75]┐         ☀️(하늘에서 떨어지는 설탕·클릭) │ ← 상단 메뉴판(4칸)
   │ │레인1═══════════════════════════════════════════│  🧟◀ │  개미: 오른쪽 밖(x=250)에서 스폰
   │ │레인2═══[🌻]══[🌱]═══════════════🥜═══════🧟▶ 걸어옴 │  장치: 컨베이어 칸 클릭 설치
   │ │레인3════════════[🌱]쿠키알▶ ● ● ●═══════🧟(헬멧)◀   │  쿠키캐논: 레인에 개미 있으면 발사
   │ │레인4══[🍒]═════════════════════════🧟(빠른)◀     │  밀크폭탄: 도화선 뒤 3×3 폭발
   │ │레인5═══════════════════════════════════🧟◀       │
   │ [빗자루×5]                                          │ ← 각 레인 왼쪽 끝 빗자루(레인당 1회)
   │ 🏠창고(왼쪽 벽 = 패배선)                                  │
   └──────────────────────────────────────────────────────┘
 (-240,-180)                                          (240,-180)

  심기: 팔레트 씨앗 클릭 → 선택장치 세팅 → 컨베이어 칸 클릭(빈 칸 + 설탕≥가격 + 그리드 안) → 심기 / 아니면 에러음
  설탕: 설탕기계가 주기적으로 자기 칸에 설탕 생성 + 하늘에서 주기적으로 낙하 → 클릭하면 +설탕(안 주우면 잠시 뒤 자동 수확)
  개미: 자기 레인 따라 왼쪽 행진 → 장치 만나면 멈춰 갉아먹음 → 장치 죽으면 계속 전진
  창고 앞(x≤개미도달X): 그 레인 빗자루 미사용 → 빗자루 발동(레인 싹쓸이·1회 소모) / 이미 사용 → 목숨−1·집 흔들림·개미 삭제
  목숨 0 → 화면 중앙 GAME OVER 배너(점수·웨이브 표시) → 깃발 재클릭으로 1웨이브부터(리셋)
```

- HUD: 좌상단에 `설탕` `웨이브` `점수` `목숨` 모니터 4종. 튜닝 변수(가격·체력 등)는 **모니터 숨김**.
- 평면 사이드뷰 레인 — 중력·점프 없음. 배경은 5개 가로 **컨베이어 띠(레인)** + 9개 세로 그리드 칸선, 왼쪽에 창고/빗자루 자리, 위쪽에 메뉴판 바. 심기 유효성은 마우스 좌표를 **칸으로 스냅**해 `격자점유` 리스트로 판정(색 감지 아님 — 정확한 칸 스냅).
- 개미는 오른쪽 밖(`개미생성X`=250)에서 무작위 레인에 스폰되어 **자기 레인 Y를 유지한 채 왼쪽으로만 행진**, 장치에 닿으면 멈춰 갉아먹고, 창고 앞(`개미도달X`=-190)에 닿으면 빗자루/목숨 처리.
- 메뉴판 4칸은 항상 보이며 4장치 모두 시작부터 사용 가능(잠금 없음 — 초등 단순화). 설탕 부족/빈 칸 아님은 **설치커서가 빨강**으로 알려준다.

> **그리드 좌표 — 전부 튜닝 손잡이에서 계산해 리스트로 저장.** Stage 깃발에서 `열X`(9개)·`레인Y`(5개)를 손잡이 값으로 만들어 add. 장치·개미·설치커서는 이 리스트만 참조 → 아이가 손잡이만 바꾸면 그리드가 통째로 바뀐다.
>
> | | X 계산 (열, col=1..9) | Scratch X | | Y 계산 (레인, lane=1..5) | Scratch Y |
> |---|------------------------|-----------|---|--------------------------|-----------|
> | 열1 | 격자시작X + 0×격자간격X | **-160** | 레인1 | 레인시작Y − 0×레인간격Y | **110** |
> | 열2 | −160 + 1×40 | **-120** | 레인2 | 110 − 1×55 | **55** |
> | 열3 | | **-80** | 레인3 | | **0** |
> | 열4 | | **-40** | 레인4 | | **-55** |
> | 열5 | | **0** | 레인5 | 110 − 4×55 | **-110** |
> | 열6 | | **40** | | | |
> | 열7 | | **80** | 창고 벽(패배선) | 격자시작X−40 근처 | **집X=-220** |
> | 열8 | | **120** | 빗자루 주차 | | **-200** |
> | 열9 | 격자시작X + 8×격자간격X | **160** | 개미 스폰 | 오른쪽 밖 | **개미생성X=250** |
>
> 기본값: `격자시작X=-160`, `격자간격X=40`, `레인시작Y=110`, `레인간격Y=55`, `열개수=9`, `레인개수=5`. 개미가 창고을 때리는 트리거선 `개미도달X=-190`.
> **칸 스냅 공식**(설치커서): `설치열 = round((mouse x − 격자시작X)/격자간격X)+1` (1~열개수 클램프), `설치레인 = round((레인시작Y − mouse y)/레인간격Y)+1` (1~레인개수 클램프). 그 칸 중심 = `item 설치열 of 열X`, `item 설치레인 of 레인Y`. 격자 인덱스 = `(설치레인−1)×열개수 + 설치열` (1~45) → `격자점유` 리스트로 빈칸/점유 판정.

> **아트 방향**: 모두 정면 사이드뷰, `don't rotate`(개미는 왼쪽 향해 걷지만 코스튬은 안 뒤집힘 — 방향=-90 세팅해도 rotationStyle이 don't rotate라 코스튬 정면 유지, 이동은 `change x by -내속도`로 처리). **귀여운 만화 톤**(무섭지 않게): 개미=초록 얼굴·멍한 눈·헤벌린 입(기본), 주황 헬멧 모자(헬멧·체력↑), 빨간 운동화·팔 흔듦(빠른). 장치=웃는 설탕기계 / 통통한 쿠키캐논 / 눈 달린 초코벽 / 반짝이는 밀크폭탄 두 알. 설탕=노란 태양 이모지풍. 개미 3종·장치 4종은 **각각 다른 코스튬**으로 한눈에 구분.
> **레인 감지 핸드셰이크(캐슬 디펜스 자동조준 변형)**: 쿠키캐논가 발사 직전 `조준레인=내레인`·`조준탑X=x`·`조준적있음=0` 세팅 후 `개미레인확인`을 **broadcast and wait**. wait 없는 개미 수신 스크립트가 **클론 순서대로 원자 실행** → "내 레인이 같고 내가 그 슈터 오른쪽에 있으면 `조준적있음=1`". 경쟁 조건 없이 "이 레인에 쏠 개미가 있나?" 판정. 최솟값 리덕션 대신 **불리언 OR 리덕션**(캐슬의 거리-최솟값을 단순화).
> **광역/단일 데미지 통일(`타격` 방송)**: 쿠키캐논(단일·작은 반경)·밀크폭탄(광역·큰 반경)·빗자루(질주 스윕)가 **모두 같은 `타격` broadcast-and-wait** 사용. 폭심(`폭발X/Y`)·`폭발데미지`·`폭발반경` 세팅 후 broadcast → 반경 안 모든 개미가 원자적으로 `내체력−폭발데미지`. 처치 판정·점수·터짐 연출은 개미 본체 루프가 담당(중복 방지).
> **플로팅 숫자(say 미사용)**: 캐슬/마법 생존과 동일. 흰 0~9=데미지, 금 0~9=획득 설탕(+). `팝업종류`로 코스튬 오프셋만 다름.

## 4. 사운드 — 전용 합성(build.py `_wav_bytes` + `synth_*`), orphan 0

   └ Stage 감시: 목숨<1 → 게임상태=0
   ▼
[웨이브 클리어]  설탕+웨이브클리어설탕, 웨이브+1, 헬멧/빠른 해금 갱신, 웨이브사이대기 후 다음 웨이브
   ▼
[종료]  목숨 ≤ 0 → 게임상태=0, [게임오버]
   │  게임오버 배너 show(점수·웨이브) / 잔여 개미·장치·쿠키알·설탕·빗자루 클론 자기 삭제
   ▼
[다시 시작]  초록 깃발 재클릭(설탕·목숨·웨이브·격자 기본값으로 리셋)
```

> **템포 설계(시후용)**: 첫 웨이브 대기는 짧게(5초·설탕기계 하나 심을 시간), 웨이브 사이도 4초. 설탕 경제는 읽기 쉽게(설탕기계 8초·하늘 12초·자동수확 8초로 놓쳐도 손해 적게). 쿠키알 발사 간격(1.5초)으로 클론 상한 → 렉 없음. 심기·수확·발사·처치마다 전용 효과음으로 손맛. 빗자루가 위기를 화끈하게 구해주는 카타르시스.

## 7. 블록 흐름 (스프라이트별 의사코드)

> 모든 forever 루프 끝에 `wait` 넣어 CPU 폭주 방지(이동/발사 틱 0.05초, 갉기 0.1초). **매직넘버 금지** — 항상 튜닝 변수 참조. "좌표까지 거리"는 아래 공통 헬퍼.

> **공통: 좌표(tx,ty)까지 거리** (개미 타격·설탕 도달 등)
> ```
> dist = sqrt( ((x position - tx)*(x position - tx)) + ((y position - ty)*(y position - ty)) )
> ```
> 개미/쿠키알는 레인 고정 수평 이동이라 `point in direction` 대신 `change x by` 사용(코스튬 안 뒤집힘).

### Stage

**(A) 깃발 클릭 → 변수 전부 초기화(한 곳) + 리스트 빌드 + 게임시작**
```
when green flag clicked
  # ── 개조 손잡이(튜닝) 기본값: 여기 숫자만 바꾸면 게임이 달라진다 ──
  # 경제/자원
  set 기본설탕=50 ; set 하늘설탕량=25 ; set 설탕기계생산량=25 ; set 설탕기계간격=8
  set 하늘설탕간격=12 ; set 자동수확대기=8 ; set 처치설탕=0 ; set 웨이브클리어설탕=25 ; set 시작목숨=3
  # 웨이브/스폰
  set 기본개미수=5 ; set 웨이브당개미증가=2 ; set 개미간격=3.5 ; set 웨이브체력증가=2
  set 웨이브속도증가=0.05 ; set 첫웨이브대기=5 ; set 웨이브사이대기=4
  set 헬멧해금웨이브=2 ; set 빠른개미해금웨이브=3 ; set 도달반경=15
  # 장치
  set 설탕기계_가격=25 ; set 설탕기계_체력=4
  set 쿠키캐논_가격=50 ; set 쿠키캐논_체력=4 ; set 쿠키캐논_공격력=1 ; set 쿠키캐논_간격=1.5 ; set 쿠키알속도=8 ; set 쿠키알반경=18
  set 초코벽_가격=25 ; set 초코벽_체력=40
  set 밀크폭탄_가격=75 ; set 밀크폭탄_체력=1 ; set 밀크폭탄_데미지=30 ; set 밀크폭탄_반경=90 ; set 밀크폭탄_퓨즈=1.0
  # 개미
  set 기본개미_체력=5 ; set 기본개미_속도=0.6
  set 헬멧개미_체력=12 ; set 헬멧개미_속도=0.6
  set 빠른개미_체력=3 ; set 빠른개미_속도=1.2 ; set 개미물기력=0.3
  # 빗자루/그리드
  set 빗자루속도=12
  set 격자시작X=-160 ; set 격자간격X=40 ; set 레인시작Y=110 ; set 레인간격Y=55
  set 열개수=9 ; set 레인개수=5 ; set 개미생성X=250 ; set 개미도달X=-190
  # ── 진행 상태 ──
  set 게임상태=1 ; set 웨이브=1 ; set 점수=0 ; set 설탕=기본설탕 ; set 목숨=시작목숨
  set 적수=0 ; set 스폰카운트=0 ; set 선택장치=0 ; set 헬멧해금=0 ; set 빠른해금=0
  set 조준적있음=0
  # ── 그리드 리스트 빌드(손잡이에서 계산) ──
  delete all of 열X ; set i=1 ; repeat 열개수 : add (격자시작X + ((i-1)*격자간격X)) to 열X ; change i by 1
  delete all of 레인Y ; set i=1 ; repeat 레인개수 : add (레인시작Y - ((i-1)*레인간격Y)) to 레인Y ; change i by 1
  delete all of 격자점유 ; repeat (열개수 * 레인개수) : add 0 to 격자점유
  delete all of 모워사용 ; repeat 레인개수 : add 0 to 모워사용
  wait 0.3
  broadcast 게임시작
```
> 빌더 노트: `i`는 리스트 빌드용 임시 전역(진행 변수에 미포함, `varI` 하나 추가 허용) 또는 인라인 카운터. `repeat` 안의 `change i by 1`은 매직넘버 1(루프 인덱스)로 허용.

**(B) 웨이브 매니저 forever** (스폰 + 클리어)
```
when I receive 게임시작
  wait 첫웨이브대기
  forever
    if (게임상태 = 1)
        broadcast 웨이브시작                     ← 종·신음·배너
        set 스폰카운트 = 0
        repeat (기본개미수 + ((웨이브 - 1) * 웨이브당개미증가))
            set 생성레인 = (pick random 1 to 레인개수)
            # ── 웨이브·해금으로 타입 결정 ──
            if (웨이브 <= 1) : set 생성타입 = 1
            else if (빠른해금 = 0) : set 생성타입 = (1 + (스폰카운트 mod 2))          ← 기본·헬멧 번갈아
            else : set 생성타입 = (1 + (pick random 0 to 2))                          ← 기본·헬멧·빠른 섞임
            change 스폰카운트 by 1
            change 적수 by 1
            broadcast 개미생성
            wait 개미간격
        wait until (적수 <= 0)                    ← 이번 웨이브 전멸까지 대기
        if (게임상태 = 1)
            change 설탕 by 웨이브클리어설탕
            change 웨이브 by 1
            if (웨이브 >= 헬멧해금웨이브) : set 헬멧해금 = 1
            if (웨이브 >= 빠른개미해금웨이브) : set 빠른해금 = 1
            wait 웨이브사이대기
    wait 0.1
```
> 빌더 노트: `적수`는 스폰 시 +1, 처치·집돌파 시 −1. `wait until (적수≤0)`은 스폰을 **전부 마친 뒤** 실행되므로 스폰 도중 잠깐 0이어도 오판 없음.

**(C) 하늘 설탕 스포너 forever**
```
when I receive 게임시작
  forever
    wait 하늘설탕간격
    if (게임상태 = 1)
        set 설탕종류 = 0

        set 설탕Y = (item (pick random 1 to 레인개수) of 레인Y)     ← 이 레인 높이까지 낙하 후 정지
        broadcast 설탕생성
```

```

### 개미 (스포너 + 클론 본체)

**(A) 깃발 초기화**
```
when green flag clicked

```

**(B) 개미생성 → 클론 1마리** (원본만)

when I receive 개미생성
  if (복제됨 = 0) : create clone of [myself]

**(C) 클론 본체** (종류·웨이브 세팅 → 레인 행진 → 갉기/도달/처치)
```
when I start as a clone
  set 복제됨 = 1
  set 내타입 = 생성타입 ; set 내레인 = 생성레인
  if (내타입 = 1)        ← 기본
      set 내체력 = (기본개미_체력 + ((웨이브 - 1) * 웨이브체력증가))
      set 내속도 = (기본개미_속도 + ((웨이브 - 1) * 웨이브속도증가))
      switch costume to [기본개미] ; set size 70
  else if (내타입 = 2)   ← 헬멧
      set 내체력 = (헬멧개미_체력 + ((웨이브 - 1) * 웨이브체력증가))
      set 내속도 = (헬멧개미_속도 + ((웨이브 - 1) * 웨이브속도증가))
      switch costume to [헬멧개미] ; set size 72
  else                   ← 빠른
      set 내체력 = (빠른개미_체력 + ((웨이브 - 1) * 웨이브체력증가))
      set 내속도 = (빠른개미_속도 + ((웨이브 - 1) * 웨이브속도증가))
      switch costume to [빠른개미] ; set size 68
  goto (개미생성X, item 내레인 of 레인Y) ; show
  forever
    if (게임상태 = 0) : change 적수 by -1 ; delete this clone
    if (게임상태 = 1)
        # 1) 갉기 vs 전진 (같은 레인 장치에 닿으면 멈춤)
        if (touching [장치]?)
            # 장치가 자기 쪽에서 내체력 안 깎음 — 장치가 스스로 닳음(장치 (C) 참조). 개미는 멈추고 씹는 소리만.
            set sound effect [pitch] to 0 ; play sound chomp
            wait 0.1                             ← 멈춰서 갉는 틱(전진 안 함)
        else
            change x by (0 - 내속도)              ← 왼쪽 전진(코스튬 안 뒤집힘)
        # 2) 창고 앞 도달 → 빗자루 or 목숨
        if (x position <= 개미도달X)
            if (item 내레인 of 모워사용 = 0)
                replace item 내레인 of 모워사용 = 1
                set 작동레인 = 내레인
                broadcast 빗자루작동             ← 이 레인 빗자루가 나를 포함해 싹쓸이
            else
                change 목숨 by -1
                broadcast 창고피격
                change 적수 by -1
                delete this clone
        # 3) 처치(타격으로 내체력 깎임 → 0이하면 점수+터짐+삭제)
        if (내체력 < 1)
            change 점수 by 1
            change 설탕 by 처치설탕
            if (처치설탕 > 0)
                set 데미지표시값=처치설탕 ; set 데미지표시x=x ; set 데미지표시y=y ; set 팝업종류=1 ; broadcast 데미지표시
            set sound effect [pitch] to 0 ; play sound zdie
            change 적수 by -1
            switch costume to [개미터짐]
            repeat 5 : change size by 8 ; change [ghost] effect by 20 ; wait 0.02
            delete this clone
    wait 0.05
```
> 빌더 노트: 갉기 판정을 **개미는 멈추고 씹기만**, **장치가 스스로 닳게**(장치 (C)) 분리 → "어느 개미가 어느 장치를?"의 클론 참조 문제를 피함. `touching [장치]?`은 같은 레인의 장치 코스튬과 겹칠 때만 참(레인 Y가 55px 간격이라 인접 레인과 안 겹침 — 장치/개미 크기 70~80 유지). 창고 앞 빗자루 분기에서 미사용이면 **삭제하지 않음**(빗자루 스윕의 `타격`이 처리 → 내체력<1 → (C)-3에서 정상 처치). 빠른개미가 빗자루 스윕보다 앞서 나갈 일 없게 `개미도달X`는 빗자루 주차 X(-200)보다 오른쪽(-190)로 둠.

**(D) 타격 받으면 반경 안일 때 데미지** — wait 없는 원자 실행
```
when I receive 타격
  if (복제됨 = 1) and (게임상태 = 1)
      if ( sqrt(((x - 폭발X)*(x - 폭발X)) + ((y - 폭발Y)*(y - 폭발Y))) <= 폭발반경 )
          change 내체력 by (0 - 폭발데미지)
```
> **wait/yield 절대 없음** → `타격 and wait`가 모든 개미를 원자 실행해 광역(밀크폭탄·빗자루)·단일(쿠키알)이 경쟁 없이 적용. 처치 판정은 (C)-3가 담당(중복 방지).

**(E) 레인 확인 보고(불리언 OR 리덕션)** — wait 없는 원자 실행
```
when I receive 개미레인확인
  if (복제됨 = 1) and (게임상태 = 1)
      if (내레인 = 조준레인) and (x position > 조준탑X)
          set 조준적있음 = 1
```
> **wait 없음** 필수. "내 레인이 슈터와 같고 내가 슈터 오른쪽이면 표적 있음". 여러 개미가 있어도 OR로 합쳐짐(누가 세팅해도 1). 슈터 왼쪽/다른 레인 개미는 무시 → 쿠키알는 자기 레인 앞 개미에게만 쏨.

**(C) 클론 본체** (종류 세팅 + 종류별 동작 루프)
```

  set 복제됨 = 1
  set 내타입 = 설치타입 ; set 내레인 = 설치레인 ; set 내열 = 설치열
  goto (설치X, 설치Y) ; set 발사쿨 = 0 ; set 퓨즈 = 0
  if (내타입 = 1) : set 내체력=설탕기계_체력 ; switch costume to [설탕기계] ; set size 75
  else if (내타입 = 2) : set 내체력=쿠키캐논_체력 ; switch costume to [쿠키캐논] ; set size 75

  else : set 내체력=밀크폭탄_체력 ; switch costume to [밀크폭탄] ; set size 75
  show
  # ── 밀크폭탄는 도화선 뒤 즉시 폭발하고 종료 ──
  if (내타입 = 4)
      wait 밀크폭탄_퓨즈
      set 폭발X=x ; set 폭발Y=y ; set 폭발데미지=밀크폭탄_데미지 ; set 폭발반경=밀크폭탄_반경
      set sound effect [pitch] to 0 ; play sound cherry
      broadcast 타격 and wait                          ← 반경 안 개미 몰살
      set 데미지표시값=밀크폭탄_데미지 ; set 데미지표시x=x ; set 데미지표시y=y ; set 팝업종류=0 ; broadcast 데미지표시

      replace item (((내레인 - 1) * 열개수) + 내열) of 격자점유 = 0
      repeat 5 : change size by 12 ; change [ghost] effect by 20 ; wait 0.02
      delete this clone
  # ── 설탕기계/쿠키알/초코벽 공통 루프 ──
  forever
    if (게임상태 = 0) : delete this clone
    if (게임상태 = 1)
        # 종류별 능동 동작
        if (내타입 = 1) and (발사쿨 <= 0)               ← 설탕기계: 설탕 생산
            set 설탕종류=1 ; set 설탕X=x ; set 설탕Y=y
            broadcast 설탕생성
            set 발사쿨 = 설탕기계간격
        if (내타입 = 2) and (발사쿨 <= 0)               ← 쿠키알: 레인에 적 있으면 발사
            set 조준레인=내레인 ; set 조준탑X=x ; set 조준적있음=0
            broadcast 개미레인확인 and wait
            if (조준적있음 = 1)
                set 발사X=x ; set 발사Y=y ; set 발사레인=내레인
                set sound effect [pitch] to 0 ; play sound pea
                broadcast 쿠키알발사
                set 발사쿨 = 쿠키캐논_간격
        # 개미에게 갉힘(닿아 있으면 닳음)
        if (touching [개미]?)
            change 내체력 by (0 - 개미물기력)
        # 죽음 → 칸 비우고 삭제
        if (내체력 < 1)
            replace item (((내레인 - 1) * 열개수) + 내열) of 격자점유 = 0
            switch costume to [장치터짐]
            repeat 3 : change [ghost] effect by 25 ; wait 0.03
            delete this clone
        change 발사쿨 by -0.05
    wait 0.05
```
> 빌더 노트: 갉힘은 **장치가 스스로 `내체력−개미물기력`**(0.05틱). 여러 개미가 겹쳐도 `touching [개미]?`는 한 번만 참이라 과도 중첩 없음(원하면 겹친 수만큼 빠르게 닳게 확장 가능 — 3층 미션). 쿠키캐논_간격이 발사 상한 역할(클론 폭주 방지). 설탕기계는 `발사쿨`을 생산 타이머로 재사용. 밀크폭탄는 루프에 안 들어가고 (C) 상단에서 폭발 후 종료.

**(C) 클론 본체** (하늘 낙하 or 설탕기계 등장 → 클릭/자동 수확)
```

  set 복제됨 = 1 ; set 내종류 = 설탕종류 ; set 수명 = 0
  switch costume to [설탕] ; set size 70 ; go to front

  repeat until ( (mouse down? and touching [mouse-pointer]?) or (수명 > (자동수확대기 / 0.05)) or (게임상태 = 0) )
      change 수명 by 1
      wait 0.05
  if (게임상태 != 0)
      change 설탕 by 하늘설탕량
      set 데미지표시값=하늘설탕량 ; set 데미지표시x=x ; set 데미지표시y=y ; set 팝업종류=1 ; broadcast 데미지표시

> 빌더 노트: 클릭 감지는 `mouse down? and touching [mouse-pointer]?`(간단·확실). `자동수확대기 / 0.05`는 틱→초 환산(연출 상수 0.05 인라인 허용). 설탕기계 생산 설탕(`내종류=1`)도 같은 값(`하늘설탕량`)을 줌 — 별도로 하고 싶으면 `설탕기계생산량` 참조로 분기(2층 미션). 놓쳐도 자동 수확이라 초등도 손해 적음.

### 설치커서 (칸 스냅 미리보기 + 배치)

```
when green flag clicked
  hide ; set rotation style [don't rotate] ; set [ghost] effect to 45

when I receive 게임시작
  forever
    if (선택장치 > 0) and (게임상태 = 1)
        # 마우스 → 칸 스냅
        set 설치열 = ((round ((mouse x - 격자시작X) / 격자간격X)) + 1)
        if (설치열 < 1) : set 설치열 = 1
        if (설치열 > 열개수) : set 설치열 = 열개수
        set 설치레인 = ((round ((레인시작Y - mouse y) / 레인간격Y)) + 1)
        if (설치레인 < 1) : set 설치레인 = 1
        if (설치레인 > 레인개수) : set 설치레인 = 레인개수
        set 설치X = (item 설치열 of 열X) ; set 설치Y = (item 설치레인 of 레인Y)
        goto (설치X, 설치Y) ; show ; go to front
        # 유효성: 그리드 안(마우스가 실제 칸 위) + 빈칸 + 설탕≥가격
        if ( (abs(mouse x - 설치X) <= (격자간격X / 2)) and (abs(mouse y - 설치Y) <= (레인간격Y / 2))
             and (item (((설치레인 - 1) * 열개수) + 설치열) of 격자점유 = 0)
             and (설탕 >= (가격 of 선택장치)) )
            set [color] effect to 0 ; set [ghost] effect to 30          ← 초록/밝게(가능)
        else
            set [color] effect to 100 ; set [ghost] effect to 55         ← 빨강/흐리게(불가)
    else
        hide
    wait 0.03

when this sprite clicked
  # 클릭 시 유효성 재확인 후 심기 (위 forever 가 이미 설치열/레인/X/Y 세팅해 둠)
  if ( (선택장치 > 0) and (게임상태 = 1)
       and (abs(mouse x - 설치X) <= (격자간격X / 2)) and (abs(mouse y - 설치Y) <= (레인간격Y / 2))
       and (item (((설치레인 - 1) * 열개수) + 설치열) of 격자점유 = 0)
       and (설탕 >= (가격 of 선택장치)) )
      change 설탕 by (0 - (가격 of 선택장치))
      replace item (((설치레인 - 1) * 열개수) + 설치열) of 격자점유 = 선택장치
      set 설치타입 = 선택장치
      set sound effect [pitch] to 0 ; play sound plant
      broadcast 장치설치
  else
      set sound effect [pitch] to 0 ; play sound error
```
> 빌더 노트(`가격 of 선택장치`): if/else if 분기로 산출 — `선택장치=1→설탕기계_가격, 2→쿠키캐논_가격, 3→초코벽_가격, 4→밀크폭탄_가격`. 위 두 곳(초록/빨강 판정, 클릭 심기)에 각각 펼치거나, 매 프레임 `set 현재가격 = (분기)` 임시 변수로 캐시(진행 변수 하나 추가 허용). `abs`는 `(( )*( ))`의 sqrt나 `if <0` 분기로 대체 가능(Scratch에 abs 연산 있음). `round` 스냅으로 마우스 근처 칸에 자석처럼 붙되, 칸 반경 밖이면 불가(그리드 밖 클릭 방지).

## 9. 🎯 개조 미션 사다리 (README 에 수록)

> "숫자 바꾸기 0층"에서 "관계식 1층", "조건 2층", "새 메커닉 4층"으로. 각 미션은 5.1 튜닝 변수 또는 Stage (A) 초기화/리스트만 건드린다.

### 0층 — 숫자 하나 바꾸기 (무대 초록 깃발 스크립트)
- **설탕 부자**: `기본설탕` 을 `50` → `500` 으로. 시작부터 장치를 잔뜩!
- **설탕 폭발**: `설탕기계간격` 을 `8` → `2` 로. 설탕기계가 설탕을 마구 뿜는다.
- **따발 쿠키알**: `쿠키캐논_간격` 을 `1.5` → `0.4` 로. 쿠키캐논이 따발총처럼(단, 개미도 많이 잡힘).
- **묵직한 밀크폭탄**: `밀크폭탄_반경` 을 `90` → `160` 으로. 한 방에 화면을 쓸어버린다. **맞을 때 뜨는 데미지 숫자도 확인!**
- **철벽 초코벽**: `초코벽_체력` 을 `40` → `120` 으로. 초코벽가 아주 오래 버틴다.
- **거북이 개미**: `기본개미_속도` 를 `0.6` → `0.2` 로. 개미가 더 느릿느릿.
- **목숨 늘리기**: `시작목숨` 을 `3` → `9` 로. 훨씬 많이 뚫려도 버틴다.
- **개미 지옥**: `개미간격` 을 `3.5` → `1` 로. 우르르 몰려온다(난이도 급상승).
- **개미 빨리 해금**: `헬멧해금웨이브`·`빠른개미해금웨이브` 를 `2`,`3` → `1`,`1` 로. 처음부터 세 개미 다!

### 1층 — 값을 식으로 묶기 (관계 만들기)
- **웨이브 비례 보상**: Stage (B) 클리어 보너스를 `웨이브클리어설탕` 대신 `웨이브클리어설탕 × 웨이브` 로 — 후반일수록 설탕이 팍팍.
- **점점 단단해지는 개미**: `웨이브체력증가` 를 `2` → `5` 로. 웨이브가 오를수록 개미 체력이 가파르게(실제 체력 = 종류체력 + (웨이브−1)×이 값).
- **처치 보상**: `처치설탕` 을 `0` → `5` 로. 개미 잡을 때마다 금색 +5 설탕 팝업이 뜬다.

### 2층 — if 조건 더하기
- **보스 웨이브**: Stage (B) 매니저에 `if (웨이브 mod 5 = 0) : set 생성타입 = 2` 추가 — 5의 배수 웨이브는 헬멧 개미만 몰려오는 보스전.
- **설탕기계 특산**: 설탕 (C)에서 `if (내종류=1) : change 설탕 by 설탕기계생산량` 로 바꿔, 설탕기계 설탕만 다른 양을 주게(하늘/설탕기계 분리).
- **위기 보너스**: Stage (D) 감시에 `if (목숨 = 1) : change 설탕 by 100` 류로 마지막 목숨일 때 응원 설탕(원하면).

### 3층 — 규칙 자체를 바꾸기 (분기)
- **떼로 갉기**: 장치 (C) 갉힘을 `touching [개미]?` 한 번이 아니라, 겹친 개미 수에 비례해 더 빨리 닳게(새 레인 카운트 broadcast).
- **얼음 쿠키알**: 쿠키알 `타격`에 닿은 개미의 `내속도`를 잠시 줄이는 슬로우(새 클론-로컬 `둔화`)를 추가 — 5번째 장치 탄생.
- **분열 개미**: 개미 (C) 처치 시 `if (내타입=3) : (같은 레인에 작은 개미 1마리 스폰)` — 빠른 개미가 죽으며 쪼개지게(스폰 채널 재사용).

### 4층 — 새 메커닉 만들기 (구조)
- **그리드 바꾸기**: `레인개수`·`열개수`·`격자간격X`·`레인간격Y` 를 바꿔 6×10 등 새 판을 만들어 보자. 리스트가 통째로 재계산되어 새 그리드가 생긴다!
- **밤 스테이지**: 배경을 어둡게 하고 하늘 설탕을 없앤 뒤(`하늘설탕간격` ↑) 설탕기계 의존도를 높이는 규칙.
- **황금 개미**: 가끔(`pick random 1 to 10 = 1`) 스폰되는 반짝이는 개미를 만들어 잡으면 설탕 5배(새 타입/색).
- **빗자루 재장전**: 웨이브 클리어 시 `모워사용` 리스트를 전부 0으로 되돌려, 매 웨이브 빗자루가 부활하는 규칙.

## 10. 학습 포인트

**보너스 액션 게임 — 수학/추상 학습 콘셉트 없음.** ([[feedback-game-design]] 준수: 데시벨/음파/산성 같은 추상 콘셉트 금지. 순수 액션 전략.) **캐슬 디펜스·마법 생존과 똑같이 "코딩 학습(한글 손잡이)"이 핵심 교육 가치**: 모든 능력치(설탕·가격·장치 체력/공격/간격·개미 체력/속도·웨이브 스케일·빗자루 속도·그리드 좌표)가 한글 튜닝 변수·리스트로 노출되어, 아이가 (0층) 숫자를 바꾸고 → (1층) 값을 식으로 묶고 → (2층) if 조건을 더하고 → (4층) 그리드/새 장치를 추가하며 **변수·리스트·연산·조건·클론·broadcast and wait** 를 게임을 망가뜨리고 고치며 체득한다. 코드 곳곳의 **노란 코멘트(가이드 투어)** 가 각 부분을 설명한다. 부수적으로 **그리드/인덱스**(`(레인−1)×열개수+열`), **불리언 리덕션**(레인에 적 있나), **반경 판정**(폭발), **자원 관리**(설탕 경제), **증가 곡선**(웨이브 스케일링)을 게임 행동으로 자연스럽게 만난다 — 어디까지나 직관적 레인 디펜스로 포장된 채.
