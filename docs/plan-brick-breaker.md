# 브릭 브레이커 (brick-breaker) — Plan

> Arkanoid / DX-Ball 감성의 **파워업 벽돌깨기**. 패들로 공을 받아 벽돌을 깨고, 낙하 캡슐로 멀티볼·레이저·캐치 등을 얻는다.

## 메타

- **폴더**: `games/brick-breaker/`
- **출력**: `벽돌깨기.sb3`
- **대상**: 초등, 직관 액션
- **Scratch 적합**: 공·패들 소수 + 벽돌 격자(≤60), 이벤트성 파워업

## 핵심 루프

1. 패들(마우스 X)로 공 받기  
2. 벽돌 파괴 → 점수, 확률 파워업 낙하  
3. 캡슐을 패들로 받기 → 효과  
4. 스테이지의 깨는 벽돌 전부 → STAGE CLEAR → 다음 패턴  
5. 공 전부 낙하시 목숨 -1, 0이면 GAME OVER  

## 파워업 (추천 세트)

| 코드 | 이름 | 효과 |
|------|------|------|
| M | 멀티볼 | 공 +2 (상한 5) |
| W | 확대 | 패들 넓게 |
| L | 레이저 | 패들 레이저 모드, 스페이스 발사 |
| C | 캐치 | 공 붙였다 스페이스로 발사 |
| P | 관통 | 벽돌 맞아도 반사 안 함(잠시) |
| S | 감속 | 공 속도 감소 |
