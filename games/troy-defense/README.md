# 트로이 디펜스 (Troy Defense)

## 조작 (QWER)

| 키 | 신 | 동작 |
|----|-----|------|
| **Q** | 아폴론 | 조준 → 맵 클릭 · 태양 광역 |
| **W** | 아레스 | 조준 → 맵 클릭 · 전쟁 강타 |
| **E** | 아르테미스 | 조준 → 맵 클릭 · 달빛 범위 |
| **R** | 제우스 | **궁극** 전역 벼락 (게임당 3회) |

웨이브 클리어 후 **1·2·3** 키로 강화 3택1.

## HUD
- **좌상단**: WAVE + 성벽 게이지 (좌 정렬)
- **상단 중앙**: 골드 변수
- **우상단**: Q W E R 스킬 아이콘

## 빌드
```bash
python3 games/troy-defense/build.py
```
