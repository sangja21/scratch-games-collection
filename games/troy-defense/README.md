# 트로이 디펜스 (Troy Defense)

## 조작 (QWER)

| 키 | 신 | 동작 |
|----|-----|------|
| **Q** | 아폴론 | 조준 → 맵 클릭 · 태양 광역 |
| **W** | 아레스 | 조준 → 맵 클릭 · 전쟁 강타 |
| **E** | 아르테미스 | 조준 → 맵 클릭 · 달빛 범위 |
| **R** | 제우스 | **궁극** 전역 벼락 (게임당 3회) |

웨이브 클리어 후 **1·2·3** 키로 강화 3택1.

## HUD
- **좌상단**: WAVE + 성벽 게이지 (좌 정렬)
- **상단 중앙**: 골드 변수
- **우상단**: Q W E R 스킬 아이콘

## 난이도 곡선 ★

**문제**: 아군은 곱셈으로 세지는데(공격력 +12/픽, 연사 ×0.6/픽, 탑 증설) 적은 덧셈으로만 세져서(배율 +0.2/웨이브) 중후반이 처졌음.

**수정**: 적 체력도 곱셈 성장으로 바꿈.

```
클리어할 때마다:  적체력배율 = 적체력배율 × 웨이브체력배수(1.15) + 웨이브배율증가(0.05)
보스 웨이브였으면: 적체력배율 = 적체력배율 × 보스후배율(1.4)
```

같이 들어간 페이싱 수정:

| 항목 | 값 | 이유 |
|------|-----|------|
| 그리스군수상한 | 30 | 후반에 50마리씩 줄줄이 나와 웨이브가 40초씩 늘어지던 것 차단. 수 대신 **체력**으로 어려워짐 |
| 간격감소 / 그리스군간격최소 | 0.02 / 0.35 | 웨이브가 오를수록 촘촘하게 몰아침 (0.8초 → 0.35초) |
| 정예웨이브 | 8 | 8웨이브부터 **경보병이 안 나옴** — 호플리테스·영웅만. 수치뿐 아니라 구성도 바뀜 |
| 속도증가상한 | 1.2 | 무한히 빨라져 포탑을 그냥 지나쳐 버리는 것 방지 |

**적 총 체력(EHP) 비교 — 초반 5웨이브는 예전과 거의 동일, 후반만 갈라짐:**

| 웨이브 | 5 | 8 | 10 | 15 | 20 | 25 |
|--------|---|---|----|----|----|----|
| 예전 | 422 | 641 | 1,376 | 3,336 | 7,008 | 13,552 |
| 지금 | 469 | 1,248 | 2,886 | 10,706 | 33,073 | 100,990 |
| 배수 | 1.1× | 1.9× | 2.1× | 3.2× | 4.7× | 7.5× |

## 난이도 핸들 (Stage 변수)

| 변수 | 기본 | 효과 |
|------|------|------|
| **웨이브체력배수** | 1.15 | ★ 제일 큰 핸들. `1.0` = 예전 곡선(후반 처짐) · `1.10` 완만 · `1.25` 가혹 |
| 웨이브배율증가 | 0.05 | 덧셈 성장분. 곱셈과 나란히 두고 비교해 보기 좋음 |
| 보스후배율 | 1.4 | 보스(5·10·15…) 잡을 때마다 추가로 곱해지는 값 |
| 그리스군수상한 | 30 | 한 웨이브 최대 마리수 |
| 그리스군간격 / 간격감소 / 그리스군간격최소 | 0.8 / 0.02 / 0.35 | 몰려오는 밀도 |
| 정예웨이브 | 8 | 경보병이 사라지는 웨이브. `99` 로 두면 끝까지 섞여 나옴 |
| 속도증가상한 | 1.2 | 적 속도 보너스 최대치 |
| 강화량 / 강화골드량 | 6 / 180 | **아군** 쪽 성장 속도 (공격력 = 강화량×2 씩 증가) |

> 튜닝 실험거리: `웨이브체력배수`를 1.0으로 두고 한 판, 1.15로 두고 한 판 → "덧셈으로 세지는 적 vs 곱셈으로 세지는 적"이 몇 웨이브부터 갈라지는지 눈으로 보기.
