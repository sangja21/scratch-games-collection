# 벽돌깨기 (Brick Breaker)

Arkanoid / DX-Ball 감성의 **파워업 벽돌깨기**. 패들로 공을 받아 벽돌을 깨고, 낙하 캡슐로 능력을 얻습니다.

## 조작

| 입력 | 동작 |
|------|------|
| ← → 또는 A D | 패들 이동 |
| 스페이스 | 공 발사 · 캐치 시 재발사 · 레이저 모드 시 발사 |

## 파워업 (벽돌 파괴 시 확률 드롭)

| 코드 | 효과 |
|------|------|
| **M** 멀티볼 | 노란 보너스공 +2 (최대 `멀티볼최대`) — 떨어져도 목숨 유지 |
| **W** 확대 | 패들 넓게 |
| **L** 레이저 | 패들 레이저, 스페이스로 발사 |
| **C** 캐치 | 공이 패들에 붙음 → 스페이스로 발사 |
| **P** 관통 | 벽돌에 맞아도 반사하지 않음 |
| **S** 감속 | 공속도 감소 |

## 벽돌

- **일반** (6색) — 1히트  
- **단단함** — 2히트 (금 가면 갈라짐)  
- **폭발** — 파괴 시 보너스 점수  
- **보스 (스테이지 5)** — 큰 왕벽돌 HP 12, 금 가면 3페이즈, 맞을 때 점수·파워/방해 드롭. **보스만 잡으면 스테이지 클리어** (호위 남아도 OK)

## 보스 판 (스테이지 5)

- 중앙 왕벽돌 + 모서리 호위(단단/폭탄/일반)
- 모니터 `보스체력` 표시
- 격파 시 점수 +300 → 클리어 연출 → (전 스테이지 돌파 시) 풀 리셋 루프

## 난장판(카오스) 연출 — 자동으로 팡팡 터짐

시간이 지날수록 저절로 정신없어집니다. 파워업을 안 먹어도 자동 발동:

| 이벤트 | 동작 | 손잡이(초/개수) |
|--------|------|-----------------|
| **멀티볼 웨이브** | 주기적으로 노란 보너스공이 무더기로 쏟아짐(최대 `멀티볼최대`) | `웨이브간격`(4), `웨이브개수`(3) + 광란레벨 |
| **레이저 광란** | 주기적으로 패들이 레이저 모드가 되어 자동 연사 (시간제한) | `레이저간격`(7), `레이저연사`(16발) |
| **공속 상승** | 시간이 갈수록 공이 점점 빨라짐 | `공속상승간격`(6), `공속상한`(28) |
| **광란레벨↑** | 12초마다 상승(최대 6) → 웨이브 규모가 커짐 | — |
| **번쩍 / 스파크** | 이벤트마다 화면 번쩍 + 파편 폭발 + 배경 색 드리프트 | — |

> 강도는 위 손잡이(Stage 변수)로 조절합니다. 너무 정신없으면 `웨이브개수`↓·`아이템확률`↓, 렉이 있으면 `멀티볼최대`↓.

## 진행

- 스테이지 5종 패턴, 클리어 시 다음 스테이지
- **5스테이지까지 모두 클리어**하면 공·벽돌·파워업·광란 상태를 전부 비우고 **목숨 3·점수 0·1스테이지**로 깔끔히 재시작
- **주황 메인공**만 지키면 됨 — 떨어지면 목숨 -1 (0이면 GAME OVER)
- **노란 보너스공**(멀티볼)은 떨어져도 목숨 그대로
- 점수 / 목숨 / 스테이지 모니터

## 한글 손잡이 (Stage)

| 변수 | 기본 | 의미 |
|------|------|------|
| 공속도 | 22 | 공 기본 속력 (S 감속 시 12) |
| 아이템확률 | 22 | 1~100, 파워업 드롭 확률 |
| 멀티볼최대 | 5 | 동시 공 상한 |
| 패들기본 | 100 | (확장용) |
