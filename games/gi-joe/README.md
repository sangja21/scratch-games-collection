# 지아이조

> 옆보기 **탱크 곡사**. 초록 탱크가 각도를 올리고, 스페이스로 파워를 담아 포탄을 떨어뜨린다.

포트리스(포격)는 이 게임으로 대체되었습니다. 점프·재장전·방패는 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| **← →** | 이동 (총구 좌우) |
| **↑ ↓** | 곡사각 (5~80°) |
| **space** | 누르는 동안 파워 충전, 떼면 발사 (짧게=약, 길게=강) |
| **X** | 수류탄 |
| 초록 깃발 | 시작 / 다시 |

## 게임 흐름

1. 왼쪽 전선에 초록 탱크가 있습니다. 포신이 곡사각을 가리킵니다. ↑↓ 로 각도를 올리면 포탄이 포물선을 그립니다.
2. **한 칸 상자**는 위로 딛고 올라갑니다. **두 칸 벽**은 막히니 각도를 올려 너머에 떨어뜨리세요. 포탄은 착탄하면 **뻥!** 불꽃 폭발하고, 근처 적을 잡습니다.
3. 적은 빨간/회색 탱크. 사정거리에 닿으면 멈춰 곡사합니다. 가끔 **뒤쪽**에서도 나옵니다.
4. **space를 짧게** 누르면 약한 포탄, **오래 누르면** 강한 포탄. 누르는 동안 아래 **파워 게이지**가 찹니다. 최대까지 누르면 자동발사.
5. **체력 5**. 포탄·몸통 박치기에 1씩 깎입니다. 0이면 폭발 후 게임오버.
6. 뭉친 적은 X 수류탄.
7. **16킬**마다 잠깐 정지한 뒤 **새 지형과 배경**. 1~5는 잡탱크 맵(사막·협곡·밤·폭풍·초원), **6번째는 보스전**(대형 전차 1대). 보스를 잡으면 다음 사이클(7=사막…)이 더 빠르게 이어집니다.

## 개조 핸들

무대 초록 깃발 맨 위 변수로 손맛을 바꿉니다. `조준속도` 로 각도 조절 빠르기를, `웨이브킬` 로 맵이 바뀌기까지 처치 수를, `파워속도` · `최소파워` · `최대파워` · `파워배율` 로 차지감과 사거리를 바꿉니다. `브금볼륨` 으로 철갑 탱크 BGM 크기를 조절합니다.
